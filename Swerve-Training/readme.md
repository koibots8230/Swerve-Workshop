# Swerve Workshop

## Purpose
The purpose of this workshop is to teach you how to create your own swerve drive. This will be accomplished through small objectives that must be completed before moving on to the next section.

For example, an objective might be **simulating the robot driving**. You are encouraged to try and complete these objectives on your own first. However, each section will include:
- An explanation of any new concepts
- A written guide to follow
- Example code (if necessary)

The example code should be your **last resort** or used to check your work.

**Important note:** Creating a swerve drive is challenging, but everyone here is smart and capable of building their own drivetrain. Don’t get discouraged,**you’ve got this!**

## Module One
For this module, you will:
1. Branch off of the `start` branch (the one we’re currently on).
2. Name your new branch:  ```[Your_Name]_SwerveDrive```
Example: `Conrad_SwerveDrive`

This branch includes the vendor dependencies and initial files you will need, but not all subsystems.

- [Get Alliance Color](https://docs.wpilib.org/en/stable/docs/software/basic-programming/alliancecolor.html)

- *Focus on the introduction to kinematics and the chassis speeds class and both swerve sections.*

- *This will not be repeated later. You are expected to know how to use units.*
